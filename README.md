# zh-hant-ui-feed

本项目为《闪耀星骑士》（ティンクルスターナイツX）的 UI 与剧情繁体中文汉化项目。本仓库为私密主仓库的公开中转仓库，用于对外提供汉化词库更新、公开版安装包及相关说明。

源码、构建过程与内部维护资料保存在私密主仓库；本仓库承接可公开的汉化内容与更新分发。

## 汉化与更新

项目整合原有剧情汉化，并维护 UI 词库及公告、帮助页面的繁体中文翻译。各版本的实际覆盖范围、兼容版本与已知问题，以对应发布说明为准。

插件通过 `latest.json` 获取词库版本信息，再读取 `objects/` 中对应的词库文件；历史词库对象保留，供版本核对与回退使用。

## 公开安装包

公开安装包使用官方原版作为底包，制作繁体中文纯汉化共存版，采用独立包名，可与原版同时安装。安装包通过本仓库的 Releases 分发。

当前 01.03.16 候选版本已完成安装与冷启动检查；DMM 登录、战斗，以及游戏内公告和帮助页面的实际显示仍待实机验证。
